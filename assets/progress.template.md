# Progress and Resume State

## Workspace identity

Record absolute path, branch/HEAD or non-Git identity, contract revision, comparison
base, and modified/untracked files. Preserve existing user changes.

## Completed work

List task IDs, implemented behaviors, and affected interfaces.

## Verification evidence

Record commands, working directories, exit codes, outputs/artifact paths, and
unavailable checks. Track consecutive failures by root cause.

## Decisions and blockers

Record confirmed/delegated choices, unresolved assumptions, pending checkpoint
IDs, and whether independent review is still required.

## Next action

Name the next task and prerequisites. State whether implementation is allowed,
paused for a user answer, or paused for a manually opened chat.
